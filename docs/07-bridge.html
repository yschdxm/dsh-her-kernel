方向路径是否审核

登录二维码

  1. NapCat 未登录时把 qrcode.png 写在容器内。
  2. 面板读取 /qq-bridge/qrcode 显示图片，并显示文件年龄。
  3. 刷新按钮调用 /qq-bridge/qr/refresh：登录 NapCat WebUI → 请求 RefreshQRcode → 容器重写图片 → 面板重新拉取。
  4. 仅改浏览器缓存参数无法得到新码（这是旧实现失效的原因）。
  5. 进程异常时用「重启 NapCat」：容器重启后重新出码并重连反向 WS。
状态阶段含义
容器未运行docker 进程不在
启动中已运行但尚未出码
等待扫码登录二维码文件较新
二维码可能已过期文件超过约 3 分钟未更新
在线登录成功且推送已连接

HTTP 接口一览

路径方法用途
/qq-bridge/statusGET阶段、容器、登录、推送、二维码年龄
/qq-bridge/qrcodeGET当前二维码 PNG
/qq-bridge/qr/refreshPOST请求 NapCat 重新出码
/qq-bridge/napcat/restartPOST重启容器
/qq-bridge/rulesGET/POST读写出站审核规则

安全边界

  • 不把可直接发送的接口暴露给角色工具。
  • token 文件不进入前端、不写进日志。
  • 群消息默认白名单；私聊仅联系配置的管理员。
