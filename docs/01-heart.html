心绪层

情绪与念头合并后的单层状态。表情、主动规则、面板读数都来自这一份数据。系数在角色面板「状态 → 调节」里改，公式见下。
总览 心绪层 日子层 记忆层 通知与消息 会话与出站 规则触发 QQ 桥接

数据结构

存于 state.json 的 heart 段（版本 v3）。旧的心情七维与心思五维已合并，迁移时自动完成并备份为 state.json.bak-v2。

字段含义
base底色 0–100，整体情绪基调
dims十维数值，见下表
lastSpokeAt上次主动开口（含注入标记）时间
lastUserMsgAt主人上次发来消息的时间
lastOutboundAt上次她主动发出的时间
daily当日通知注入次数、规则注入次数
timeline主动相关短记录（句子级，不进提示词正文）
moodTimeline底色变化流水

如何变化

flowchart LR EVT[事件] --> B[bump / hookEvent] TIME[时间流逝] --> D[decay 衰减] B --> H[heart 当前值] D --> H H --> FACE[提示词注入：底色+最强维] H --> RULE[规则触发层]
  • 事件驱动：state_note、bump(kind)、hookEvent 按真实交互加减维度。
  • 衰减：每次读取或评估时按小时向基线回归；静默超过半小时后思念额外缓慢上升。
  • 强度：取十维最大值。只用于展示与阈值参考；真正是否注入由规则层决定。
  • lastSpokeAt：仅规则注入或她真实开口更新；通知注入不算开口。

设置项与工作逻辑（最小粒度）

路径：角色面板 → 状态 / 设置。每个设置项下方均附工作说明。

注入给她的内容

状态注入是散文式摘要（底色 + 最强维 + 原因），用于日常表达。规则触发注入是纯 JSON 数值，不含祈使句，详见「规则触发」页。

{
  "type": "kernel-heart",
  "rule": "miss-pm",
  "base": 61,
  "strength": 87,
  "dims": { "miss": 87, "joy": 24, ... },
  "silenceMin": 132,
  "life": { "kind": "wait", "label": "待着" },
  "fired": { "dim": "miss", "base": 70, "effective": 66, "chance": 0.75 }
}
