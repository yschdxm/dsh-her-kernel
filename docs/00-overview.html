一句话架构

内核把「她是谁、她心里什么样、她今天在做什么、她记得什么、外面谁找她」拆成若干层；层与层只通过明确的数据接口协作。渠道消息不会直接塞进对话，她用工具主动查看；出站必过安全审核。

两条主路径

路径 A · 外面有人找她

  1. QQ 消息进入桥接 → 内核 ingest → 只写消息库 + 记未读。
  2. 触发一次规则评估：若存在可弹未读 → 注入结构化通知数据（kernel-wake）。
  3. 她在自己的会话里看到数据 → 用 app_enter / app_fetch 查看 → 决定是否 app_send。
  4. 出站经过分类器 → 再发回 QQ。

路径 B · 她心里起变化

  1. 事件（被夸、被忽略、写记忆、回合结束等）触发规则评估。
  2. 无未读时按「心绪规则」匹配：维度、时间窗、忙闲、随机。
  3. 命中则注入纯数值 kernel-heart（无话术）。
  4. 她自行决定是否行动；未说出口的内容不会伪装成已发生的对话。
设计约束：没有插件级周期定时器。完全无消息、无回合、无事件的深夜不会自己醒来。需要墙钟行为时，由角色自己创建日程提醒。

配置放哪

  • ~/.dsh/her-kernel/config.json：全局数值、心绪规则、记忆策略、渠道规则。
  • <工作区>/.dsh-her/character.json：角色卡与渠道认领。
  • <工作区>/.dsh-her/state.json：心绪 + 日子状态。
  • <工作区>/.dsh-her/life-schedule.json：作息表（仅角色可改）。
  • <工作区>/.dsh-her/memory.db / messages.db：记忆与消息。
