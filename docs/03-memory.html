记忆层

三层：系统提示词永不压缩 · 对话历史可折叠 · 长期记忆永远可查。目标：上下文过长时旧对话变成记忆，移出提示词但工具仍能查回。
总览 心绪层 日子层 记忆层 通知与消息 会话与出站 规则触发 QQ 桥接

三层结构（永不混层）

flowchart TB A[系统提示词层
人设/状态/通知] -->|永不折叠| A B[对话历史层
DSH agent 会话] -->|超预算| C[先归档再折叠] C --> D[memory.db hidden 原文] C --> E[memory.db topic 摘要] C --> F[ctx.compaction 折叠历史] D --> G[memory_hidden / memory_search] E --> G A -.->|每轮完整注入| B
  • A 系统提示词：persona / 心绪 / 通知 / 渠道说明，经 systemPrompt.context 挂载，任何压缩路径不得触碰。
  • B 对话历史：渠道与唤醒消息经 followup 进入 DSH 会话；超预算时内核先写 C，再请求平台 ctx.compaction 折叠。
  • C 长期记忆：SQLite；原文进 hidden，摘要进 topic；她用工具主动查（injectFar 默认开，不自动塞每轮）。

存储

每个角色独立 memory.db。层表：

表（level）存什么
fact / lesson / topic / project / rules / soul / user长期记忆条目
hidden被移出上下文的原文（可 memory_hidden 查回）

importance 为 1–10（越高越重要）。自动归档 topic 的 source_session 为 auto-archive 或 auto-archive-llm。

预算归档流程

  1. 回合结束时统计自上次归档以来的对话字符。
  2. 若 ≥ budgetChars 且消息数 ≥ archiveMinMessages：
  3. 除最近 keepRecent 条外，原文逐条 hide；
  4. 写一条 topic：默认用会话同款模型精炼（最多 autoExtractMax 条 / 冷却 autoExtractCooldownMin 分）；正文不超过 archiveSummaryMaxChars；
  5. 若 compactEnabled：调用平台 compactNow 或 compactIfNeeded 折叠历史（失败只记日志，绝不删会话）。

她主动 memory_remember 时，若 moveOutContext 且 rememberHideContext（或工具参数 hide_context），会把本回合原文 hide，但不触发折叠。

与会话层的关系

  • 记忆不替代平台会话日志；折叠由平台完成，内核只触发并先归档。
  • 侧边整理只写库，不往对话里插「整理完成」消息。
  • 人设等系统提示词不在压缩流程中。
