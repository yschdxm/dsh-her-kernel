文件与职责

文件内容
life-schedule.json工作日/周末时间块 + 特别日期安排。仅 life_schedule / life_schedule_set 工具可改。
state.json 的 life 段当前活动、精力/兴致/想黏人、今日流水、日记提醒标记。
面板对作息只读。修改入口在她的工具侧，保证「日程完全由角色控制」。

时间块如何生效

flowchart LR NOW[当前时刻] --> BLK[按日期选块列表] BLK --> CUR[命中块 kind] CUR --> NEED[按 kind 加减 精力/兴致/想黏人] CUR --> ACT[写入当前活动] NEED --> R[心绪规则可读忙闲] ACT --> R
  • 块格式：{ from: "HH:MM", to: "HH:MM", kind: "wait|sleep|work|...", label?: "自定义" }。
  • 跨夜块（from > to）合法。
  • 没有命中任何块时，回落为「待着」。
  • 惰性推进：只有在读取状态或规则评估时才按流逝时间补算，不靠后台定时器。

活动种类（kind）与效果方向

kind 示例语义对需求的大致影响
sleep / night睡觉、深夜精力回升或下降按表；规则默认排除
wake / home起床、在家小幅回升
schedule / out上课、出门精力下降、兴致略变；规则常排除
wait / chat待着、可聊想黏人上升；规则更易命中
stars / anime / game兴趣活动兴致上升

日记提醒

  • 条件：当天日记文件不存在、已过「日记提醒点后」、且当天尚未提醒过。
  • 行为：在状态注入里加一行路径提示。不产生额外回合，不是定时器。
  • 设置：life.diaryNudgeAfterHour（面板「设置 → 日子」）。

她如何改日程

life_schedule      // 查看当前作息
life_schedule_set  // 写入工作日/周末/特别日期
                   // { weekday: [...], weekend: [...], special: {...}, note }

空日程时，状态注入会提示可用 life_schedule_set 自行安排。内核不会替她预填模板。
